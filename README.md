# BlogSpace — Frontend Blog Application

A responsive beginner-friendly blog application built with **HTML5, CSS3 and vanilla JavaScript**.

## Features
- Home page with featured stories
- Register and login forms
- Dashboard to explore published blogs
- Search blogs by title, content, category or author
- Create and publish a blog post
- Responsive layout for mobile, tablet and desktop
- Browser `localStorage` to save demo users and blog posts

## How to run
1. Download and extract this project.
2. Open the extracted `frontend_blog_application` folder.
3. Double-click `index.html` to open it in Chrome, Edge or Firefox.
4. Register an account, log in, and publish a blog.

No installation or server is required.

## GitHub upload
1. Sign in at https://github.com/
2. Select **New repository** and name it `blogspace-frontend`.
3. Choose Public (or Private if required), then create the repository.
4. Select **Add file → Upload files**.
5. Upload `index.html`, `styles.css`, `script.js`, and `README.md` from this folder.
6. Select **Commit changes**.

## Important note
This is a frontend learning/demo project. Authentication is stored locally in the browser and is **not secure for real users**. A production app needs a backend, database, password hashing, and proper authentication.
